# hxwl-04 牙科根管治疗

根管耗材计费与患者欠费核销台：按牙位登记耗材、确认费用、结账冻结、退费冲销与欠费核销。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5104

## 功能

- 牙位看板：按牙位查看耗材项数、费用、冲销、净额与状态（登记中 / 已确认 / 已结账冻结）
- 耗材计费：登记耗材项目、单价、数量、自费/医保与本次费用；缺耗材或价格非正不能确认
- 结账冻结：已结账牙位不能直接改账，更正只新建带原因的版本并保留旧值
- 退费冲销：退费只生成带原因的负数冲销，原项目金额保留
- 欠费核销：结账净额计入患者欠费；欠费未清不能排下次复诊；核销需金额与原因
- 一致性核对：每次变更即写入 localStorage，刷新后自动重算牙位、耗材、费用、冲销与版本，冲突列出牙位、项目、差额和原值

## 代码结构

- `src/data.ts` — 数据层：类型、种子数据、localStorage 持久化
- `src/rules.ts` — 规则层：确认校验、退费冲销、更正版本、欠费核销、一致性核对（纯函数）
- `src/App.tsx` — 页面层：看板、计费、核销、冲突与版本四个页签
