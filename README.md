# hxwl-04 牙科根管治疗

按牙位组织根管步骤，并提供耗材计费、退费冲销、患者欠费核销与结账更正版本管理。

## 技术栈

React + Vite + TypeScript + CSS，无额外运行时依赖；数据持久化使用浏览器 localStorage。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5104

## 架构（数据 / 规则 / 页面分层）

- `src/data/` 数据层：`types.ts` 领域结构、`seed.ts` 演示数据、`repository.ts` localStorage 读写
- `src/rules/` 规则层：纯函数，可脱离界面单独验证
  - `validations.ts` 登记 / 退费 / 更正 / 复诊 / 缴费校验
  - `billing.ts` 牙位与患者费用、欠费核算
  - `operations.ts` 状态流转（登记、结账、冲销、更正、复诊、核销）
  - `corrections.ts` 冻结牙位的更正版本（带原因、保留旧值、字段差额）
  - `conflicts.ts` 刷新后对账冲突检测（牙位、项目、差额、原值）
- `src/pages/` 页面层：React 组件，只负责录入与展示，所有判定调用规则层

## 业务规则

- 按牙位登记耗材项目、单价、数量、自费 / 医保与本次费用（= 单价 × 数量）；缺耗材或价格非正不能确认。
- 患者欠费未清不能排下次复诊；缴费按欠费额核销，不允许多缴。
- 退费不改原项目金额，只生成一条带原因的冲销记录；累计冲销不得超过原项目金额。
- 牙位结账即冻结：不可再加耗材或改阶段；更正只能新建带原因的版本，旧值完整保留。
- 每次变更整体持久化，刷新后牙位、耗材、费用、冲销与版本一致；
  对账面板会把异常（留存金额不符、孤儿 / 超额冲销、版本链断裂等）列为冲突，显示牙位、项目、差额与原值。
